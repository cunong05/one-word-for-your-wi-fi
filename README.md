## Entry

> Limbo

## The idea

Wi-Fi lives in limbo: not quite connected, not quite gone — bars full, pages
loading nowhere, the signal hovering in that in-between place where every
video call freezes mid-sentence. "Limbo" is funny, true, and fresh, and it
works perfectly as a network name: join *Limbo* and see how long you last.
